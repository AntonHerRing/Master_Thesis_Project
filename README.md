The main files for the project are located in "Project_LET", and the equivalent files for the implicit version is in "Project_without_LET".

The Schematic for the adapter board for the ES-Lab-Kit can be found in "Adapter_Board_Schematics".

Button functionality on the ES-Lab-Kit::

(SW_5) - Move Left

(SW_6) - Move Right

(SW_7) - Reset

(SW_8) - Override motor to stop (not toggelable).

Note: When SW_8 override has been pushed, the program has to be reset. It is not a toggle.
